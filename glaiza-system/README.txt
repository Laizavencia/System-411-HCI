Inosloban (with Barangay Services features)
1. Copy this folder to htdocs (XAMPP) or your host.
2. Import database.sql in phpMyAdmin. The schema creates the database as barangayglaiza (older references may say barangay_db).
3. Set your local MySQL credentials in environment variables or edit includes/db.php if needed.
4. Add your images: assets/images/logo.jpg (or set via Settings) and assets/images/barangay.jpg (login background).
5. Admin login: admin / admin123 (you will be forced to change it). Resident login: sign up at /signup.php, then verify in admin > My Inhabitant Profile.
6. Edit includes/barangay_info.php with your real hotlines, fees and offices.
